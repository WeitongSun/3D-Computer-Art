# Assets Manager

*1 person · needs the Thing World v1.1 update · [all roles](README.md)*

**Your job:** Keep the whole class organized: who makes what, where it goes, what has been handed in.

## How

1. Check the role folders in `01_Hand-in` on the class hard drive after each class: who handed in, what's missing.
2. Keep the Miro tracker up to date every time a file comes in (Status + date).
3. Sort the sticky notes on the Miro CITY MAP: nothing blocks a path, big landmarks at the edges.
4. Remind people: run **3. Check My Work** before exporting; only the newest file counts.

## Common questions

**Someone's file is missing from the hard drive.**
Remind them: 3. Check My Work → 4. Export My Work → copy to `01_Hand-in/TheirRole`.

**Two files from the same person?**
The newest one counts (the date is in the file name). Keep the old ones; don't delete anything.

**Someone's piece blocks a path on the city map.**
Move their sticky and tell them; talk to the Landscape team.
