# Textures

*1–2 people · needs the Thing World v1.1 update · [all roles](README.md)*

**Your job:** Make sure the final city doesn't look strange — without making everyone look the same.

## How

1. With Landscape: make the ground materials (roads, grass, plazas) — the base every piece stands on.
2. Visit each classmate's piece in their World Test Scene. Check: texture scale (is a brick 20 cm?), brightness, how it meets the ground.
3. Suggest fixes; everyone keeps their own style.
4. If you make a material for others: **World Building → Shared: Create Shared Material**, then **Shared: Export My Shared Library** → hard drive `02_Shared`.

## Limits

textures ≤ 2048 px · URP/Lit only

## Work with

Landscape first, then every asset maker one by one

## Checklist

- [ ] Session 5: first ground materials
- [ ] Session 7: visited everyone
- [ ] Session 8: final materials

**3. Check My Work** (no red) → **4. Export My Work** → copy the file to the hard drive `01_Hand-in/YourName`.
